Install EnvStore

1. Drag EnvStore.app to Applications.
2. Open EnvStore from Applications.
3. If macOS blocks this unsigned preview, open System Settings > Privacy & Security and choose Open Anyway for EnvStore.
4. Return to EnvStore. First-run setup installs the CLI, registers the local broker, and installs the agent skill.

Never disable Gatekeeper globally. EnvStore does not need administrator access.
